[Neo Mobile App] Implement MAUI equation system builder with visual matrix interface

Add complete mobile application for visually constructing and solving linear equation
systems following the MVVM pattern with .NET MAUI.

Key Features:
- Visual equation builder with dynamic coefficient entry
- Variable count picker (2-5 variables)
- Real-time input validation with visual feedback
- Add/remove equation rows dynamically
- Integration with Neo.Core IEquationSolver service
- Async solving with loading state management
- Error handling and result display

Architecture:
- Views: MatrixBuilderPage with XAML UI
- ViewModels: MatrixBuilderViewModel with CommunityToolkit.Mvvm
- Models: EquationRow for equation data structure
- Converters: IsValidDoubleConverter, InverseBoolConverter

Implementation Details:
- Use BindableLayout for dynamic coefficient entries
- DataTrigger for validation highlighting (red background)
- Task.Run for background solving operations
- INotifyPropertyChanged for UI updates
- Dependency injection for solver and view models
